# Family Health Assistant

An agentic medical assistant for families. Users talk naturally (Egyptian
Arabic or English) or send photos of prescriptions and lab reports. A master
agent understands each request, decides what to do, and answers from a
curated medical knowledge base (RAG) with citations.

> **Disclaimer:** This system is not a doctor. It never diagnoses, prescribes,
> or changes doses. Medical content and red-flag rules must be reviewed by a
> qualified professional before any real-world use.
